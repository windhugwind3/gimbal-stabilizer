## 三、下单前确认

- [ ] 电机是**云台电机**（低 KV、高电阻），不是航模高 KV 电机
- [ ] 电机极对数：问卖家要 datasheet，常见 7 对或 11 对
- [ ] AS5047P 是 SPI 版本，支持 3.3V 逻辑
- [ ] 磁铁是**径向充磁**，尺寸和编码器芯片匹配
- [ ] SimpleFOC Shield 的逻辑电压和 G431 的 3.3V 兼容
- [ ] 支架安装孔和 2208 电机匹配（问清孔距）
- [ ] 电源适配器是 12V，电流 ≥3A，接口匹配
- [ ] ST-Link 支持 SWD，能连 G431
- [ ] 关键器件买双份：核心板、驱动、电机、编码器、IMU

## 四、到货后的第一轮测试

1. **清点拍照**：所有器件摆一起拍照，记录型号和数量。
2. **电源检查**：万用表测 12V 适配器输出；检查板子电源对地是否短路。
3. **点灯**：ST-Link 连 G431，下载点灯程序。
4. **串口**：UART 打印 `hello`，确认波特率。
5. **编码器**：手转电机，串口看 AS5047P 角度是否连续。
6. **电机开环**：电源限流 0.5 A，慢速开环转动，记录电流和温度。
